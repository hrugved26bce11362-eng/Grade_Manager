# Student Grade Manager

A lightweight, terminal-based Python application for managing student records, calculating grade averages, and tracking top/lowest academic performers.

---

## Features

- **Add Students & Marks:** Record student entries along with multiple grade entries.
- **View All Records:** Display all students, their listed marks, and calculated overall averages formatted to two decimal places.
- **Identify Top & Lowest Performers:** Dynamically search and find the class topper and lowest scorer based on average grades.
- **Update Records:** Easily overwrite existing student marks.
- **Remove Students:** Delete individual student entries from the system.
- **Input Validation:** Built-in validation handles empty inputs and non-numeric entries cleanly.

## Getting Started

### Prerequisites

- Python 3.10+ installed on your machine.

1. **Clone the repository:**
   ```bash

   cd student-grade-manager
2. Run the application
   python main.py
